# Cours Julia

Cours d'introduction au langage **Julia** à la [Toulouse School of Economics](https://www.tse-fr.eu/fr)
(Master 1 et Master 2).

Ce dépôt rassemble les ressources accessibles aux étudiants :

- [le cours](cours/README.md) : le site du cours est le cours lui-même ;
- [sujets d'examen](examens/README.md) ;
- [code source du site](site/README.md), en Quarto.

**Accéder au cours : <https://ocourses.github.io/julia-tse/>**

## Cloner et mettre à jour le dépôt

```bash
git clone https://github.com/ocourses/julia-tse.git     # première fois
cd julia-tse && git pull                                # mises à jour
```

## Signaler une erreur

Ouvrez une [issue sur GitHub](https://github.com/ocourses/julia-tse/issues/new/choose),
en indiquant la page concernée.
